# TaskFlow Dashboard

Create a modern and beginner-friendly web application called Task Manager Pro.

The application should have the following features:

Dashboard showing total tasks, completed tasks and pending tasks.

Add new tasks with a title and description.

Organise tasks into categories such as School, Work and Personal.

Set deadlines for tasks.

Mark tasks as completed.

Delete tasks.

Show a progress bar indicating task completion.

Design:

Modern, clean and professional dashboard.

Green and white colour theme.

Simple sidebar navigation.

Easy-to-use buttons and forms.

Responsive design for computers and mobile phones.

Technical requirements:

Use React.

Use CSS for styling.

Make all buttons functional.

Store tasks in local storage so they remain after refreshing the page.

Keep the code clean and beginner-friendly.

Do not add unnecessary complicated features.
